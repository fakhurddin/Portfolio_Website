Overview

The problem

Intercity vans in Sindh run without published schedules, upfront fares or seat choice.

The solution

Passengers compare departures, see the fare and pick an exact seat. Drivers and owners run trips from their own apps.

My role

Product design, full-stack development and the Android app, from first sketch to launch preparation.

Built for four roles

Passengers

Search routes, pick a seat, book, track the trip and rate the driver.

Drivers

Publish trips, accept requests and confirm every pickup and drop-off.

Vehicle owners

Manage vans and drivers, set fare limits, follow every trip.

Admins

Approve users and vehicles, set route fares, handle support.

How it works

Fares are set in three layers

AdminFare range per route
OwnerLimits inside that range
DriverFinal fare; front and back seats can differ

Every layer is checked on the server, so no app can charge outside the agreed range.

Challenges solved

No double bookings

Seats are locked the moment they are chosen, so two passengers can never hold the same one.

Tracking that matches reality

Drivers confirm each stop, so passengers and owners see where the trip really is.

Payments without a gateway

Fares are paid in cash; a 50% wallet hold secures each booking.
